# TestFlightベータ試験

2026-09-08にMameCard 0.1.0（1）のTestFlight内部テストを開始しました。
2026-09-09に外部グループ「名刺ユーザーテスト」へ同ビルドを追加し、ベータ審査へ提出しました。
現在は「審査待ち」で、外部向けの招待リンクはまだありません。
ホーム画面の表示名は`Namecard Beta`です。

## 試す範囲

- iOS 17以降のNFC対応iPhoneと、販売品と同じ名刺基板・パネル・FWを使用します。
- 白黒画像の書き込み、クリーニングON／OFF、内蔵パターン、URL設定、中断後の再スキャンを試します。
- 画像・日本語テキストの編集、Library保存・再起動後の読込、AndroidとのBIN交換を試します。
- Settingsの「振動による位置案内」は任意でONにして、書き込み中の案内を確認できます。
- 4階調は編集・プレビュー・保存・BIN入出力のみです。NFC書き込みと4階調表示からの白黒移行は対象外です。

白黒の異なる画像A／Bを交互に送ると、以前の表示との取り違えを避けられます。
完了するまでiPhoneのNFCアンテナ位置へ名刺を固定してください。切断後に再スキャンの案内が出たら、
同じ名刺で再開します。表示だけ変わっても、アプリが確認保留を表示した場合はそのまま報告してください。

## 報告する内容

TestFlightのフィードバックに次を添えてください。通信ログはSettingsからコピーできます。
URLや画像など共有したくない内容がある場合は、送信前に確認してください。

- アプリのVersion／Build、iPhone機種、iOSバージョン
- 名刺の基板版・パネル・カバー、iPhoneケースの有無
- 操作、クリーニングと振動案内のON／OFF、開始前の表示状態
- 成功／試行回数、所要時間、切断回数、再スキャンで復帰したか
- エラー文、表示が実際に変わったか、該当する通信ログ

通常の試行報告は[公開前の実機計測](HARDWARE_VALIDATION.md)とは分けて記録します。
時間計測や必要な連続成功の記録を満たした結果だけを、App Store版の検証済み設定へ反映します。

## 開発者向け：試験対象の変更

`Namecard/Resources/BetaDistribution.json`で対象を設定します。現在は最低iOS 17で、
`deviceModels`と`iOSMajorVersions`が空なので、NFC対応iPhoneを広く試験できます。
端末の実際のNFC利用可否はCore NFCでも確認します。

例えばiPhone XR／iOS 18に絞る場合は次の値にします。

```json
{
  "schemaVersion": 1,
  "minimumIOSMajor": 17,
  "deviceModels": ["iPhone11,8"],
  "iOSMajorVersions": [18]
}
```

設定が欠けているか不正な場合、Betaでも表示書き込みを許可しません。
対象外の端末では編集・BIN保存・URL設定・STATUS確認を利用できます。
対象変更時はSimulatorのモデルも対象になるか確認し、UI試験の書き込みボタンの期待値を合わせてください。
通常Releaseはこの設定を使わず、`HardwareValidation.json`の実測記録を使います。
