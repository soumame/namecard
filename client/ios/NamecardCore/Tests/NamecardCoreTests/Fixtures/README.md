# Android golden BIN fixtures

These files were generated by compiling and running the repository's unmodified
`client/android/app/src/main/java/jp/namecard/nfctest/NativeImageFormat.kt`
with Kotlin 2.3.0 / Java 17. No Swift implementation participates in generation.

The input is 296 × 128 straight ARGB pixels, row-major:

```kotlin
val pixels = IntArray(296 * 128) {
    ((it.toLong() * 1103515245L + 12345L) and 0xffffffffL).toInt()
}
NativeImageFormat.encodeArgb(pixels, 296, 128, 1) // android-dot-density.bin
NativeImageFormat.encodeArgb(pixels, 296, 128, 2) // android-gray4.bin
```

The pattern exercises colored luminance, every alpha range, the Bayer matrix,
pixel layout, and both 4-gray planes. Tests compare all bytes, not just hashes.

The frame golden `4e43010234120700f000030016b84abf102030` in NCProtocolTests
was generated by the repository's `NamecardProtocol.frame(2, 0x1234, 7, 240,
byteArrayOf(0x10, 0x20, 0x30))`, extracted with its CRC routine and unchanged.
